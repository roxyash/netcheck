# netcheck

Простая страница для проверки качества связи: задержка, скорость загрузки и стабильность
соединения до нескольких серверов. Результат пользователь копирует сам, страница никуда
его не отправляет.

- `index.html` – страница, без внешних зависимостей.
- `blob.bin` – случайные данные для контрольной загрузки.
